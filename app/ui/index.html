Расширение для браузера

Браузер:
  1. Откройте страницу расширений
    Откроется новая вкладка. Путь к папке расширения скопируется сам — он понадобится в шаге 3. Не открылась — наберите адрес chrome://extensions вручную.
  2. Включите «Режим разработчика»
    Переключатель в правом верхнем углу страницы.Переключатель в левой панели внизу.
  3. Нажмите «Загрузить распакованное расширение»
    Откроется окно выбора папки: щёлкните в строку адреса вверху, нажмите Ctrl+V, затем Enter и «Выбор папки».
  4. Закрепите значок
    Значок 🧩 справа от адресной строки → 📌 рядом с «MAIRDI Загрузчик». В нём — перехват загрузок и «Скачать видео».
  1. Откройте страницу расширений
  2. Нажмите ⟳ в карточке «MAIRDI Загрузчик»
    Браузер перечитает файлы новой версии из той же папки — ничего переустанавливать не нужно.
Браузер может напоминать «Отключите расширения в режиме разработчика» — это нормально, нажмите крестик. Программа сама увидит, что расширение подключилось.

Подключение Google Диска

Один раз создайте свой ключ приложения в Google Cloud — это бесплатно и занимает около пяти минут. Пароль от Google программа не видит: вход идёт в вашем браузере.
  1. Проект. — название любое, например «MAIRDI Загрузчик».
  2. Drive API. и нажмите «Включить» (Enable).
  3. Экран входа. → «Начать»: имя приложения, ваша почта, аудитория «Внешние» (External), создать. Затем на вкладке «Аудитория» (Audience) нажмите «Опубликовать приложение» (In production) — иначе Google будет отключать вход каждые 7 дней.
  4. Ключ. → «Создать клиента» → тип «Приложение для компьютера» (Desktop app) → «Создать» → «Скачать JSON».
  5. Выберите скачанный файл ниже — или вставьте его содержимое, или Client ID и Client Secret.
При первом входе Google покажет «Приложение не проверено» — это ваше собственное приложение: нажмите «Дополнительно» → «Перейти на страницу…» → «Разрешить».
