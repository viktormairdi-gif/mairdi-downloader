# MAIRDI Загрузчик

Менеджер загрузок в духе Download Master: докачка после обрывов, 16 потоков на файл,
торренты и magnet, видео с YouTube/Instagram/TikTok/VK и ещё 1000+ сайтов, прямые ссылки
из Google Диска, Яндекс.Диска, Dropbox, OneDrive, Облака Mail.ru — и **сам раскладывает файлы по папкам**.

## Установка (вручную, один раз)

1. Запустить `bin\MairdiDownloader.exe`.
   При первом запуске программа сама скачает компоненты с официальных страниц GitHub
   (aria2, yt-dlp, deno, ffmpeg — около 250 МБ, прогресс внизу окна). Windows может спросить
   разрешение для брандмауэра — разрешить (нужно торрентам).
2. Расширение: внизу окна «🧩 Установить расширение» (или Настройки → «🧩 Расширение для браузера…») —
   мастер из 4 шагов: открывает `chrome://extensions` / `edge://extensions`, копирует путь к папке
   `extension`, дальше «Режим разработчика» → «Загрузить распакованное» → Ctrl+V. Программа сама видит,
   что расширение вышло на связь (с 1.3.2 оно присылает свою версию), и подсказывает «⟳ Обновить»,
   если в папке лежит более новая версия. Поставить расширение одной кнопкой нельзя: Chrome на Windows
   запрещает установку не из Web Store, а ключ `--load-extension` в обычном Chrome отключён.
3. Настройки → «Открывать торренты и magnet-ссылки этой программой» — Windows покажет окно
   приложений по умолчанию, выбрать «MAIRDI Загрузчик».

## Куда что попадает

```
Загрузки\
  Прайсы\<сайт поставщика>\        — по слову «прайс/цены/остатки» или по колонкам цены и товара внутри таблицы
  Документы\  PDF | Word | Таблицы | Презентации | Тексты | Договоры и счета
  Дистрибутивы\  Программы | Драйверы | Образы дисков | Android | Обновления Windows | macOS и Linux
  Программирование\  Исходники | Библиотеки и SDK | Инструменты | Базы данных | Данные
  Видео\<YouTube, Instagram…>\     Музыка   Изображения   Книги   Архивы   Торренты   Прочее
```

Архивы программа открывает и смотрит, что внутри (код, установщик, драйвер, фото).
Переложили файл вручную и отметили «запомнить» — появляется правило (по сайту или расширению).
Файлы, которые браузер сохранил мимо программы, тоже раскладываются. Кнопка «Разобрать» —
разложить старые файлы из корня папки загрузок.

## Повторно не качает

- ссылка уже скачана (YouTube-ссылки одного ролика совпадают в любом виде);
- в папке уже есть файл с тем же именем и размером — закачка останавливается в самом начале;
- после скачивания содержимое совпало с уже лежащим файлом (SHA-256) — копия не остаётся.

ПКМ → «Скачать всё равно», если повтор действительно нужен.

## Google Диск (с версии 1.1)

Слева «Google Диск → Подключить». Нужен свой ключ приложения Google (OAuth-клиент типа «Приложение для компьютера»), пошаговая инструкция — в самом окне подключения. Важно: на вкладке «Аудитория» опубликовать приложение (In production), иначе Google отключает вход каждые 7 дней.

- Разделы: Мой диск, Доступные мне, Общие диски, Недавние, Помеченные, Корзина; поиск по имени; квота.
- Двойной щелчок: папка — открыть, файл — скачать. Несколько файлов — Ctrl/Shift и «Скачать».
- Файл скачивается своим движком в 8 потоков с докачкой и раскладывается по папкам как обычно.
- Папка целиком ложится в `Google Диск\<папка>` со всей структурой; то, что уже лежит там с тем же размером, не качается.
- Документы, Таблицы и Презентации Google — в docx / xlsx / pptx.
- **Загрузка на Диск (1.2):** откройте папку на Диске → «⇪ Файлы» / «⇪ Папку» или перетащите файлы и папки из Проводника в окно. Кусками по 16 МБ, до 3 файлов одновременно; после обрыва и перезапуска программы продолжает с того, что Google уже принял. Тот же файл (имя + размер + MD5) в той же папке повторно не загружается; папки переиспользуются. Перетащенные файлы сначала копируются во временную папку программы и удаляются после загрузки; исходники не трогаются никогда.
- **Скачать в Google Диск (1.3):** галочка «☁ Сразу на Google Диск» в окне «Новая закачка», пункты «Скачать в Google Диск» / «Скачать видео в Google Диск» в меню Chrome (правая кнопка), галочка у кнопки видео в окошке расширения, кнопка «🔗 По ссылке» (или Ctrl+V, перетаскивание ссылки) в открытой папке Диска. Программа качает как обычно, раскладывает и загружает на Диск в `Загрузки\<папка раскладки>` (или в открытую папку Диска); торрент целиком — со структурой, раздача останавливается. Копия на компьютере удаляется, только когда Google подтвердил тот же размер; уже лежавший у вас файл (дубль) не удаляется никогда. Повторная ссылка — «уже на Google Диске». ПКМ по готовой закачке → «Загрузить на Google Диск» (копия остаётся). Аккаунт, папку на Диске и «оставлять копию» — в Настройках.
- **«Отправить → Google Диск (MAIRDI)»** в контекстном меню Проводника — включается в Настройках. Выбранные файлы ждут в окне, пока вы откроете нужную папку Диска и нажмёте «Загрузить сюда».
- Вход идёт в браузере (Chrome, если установлен), пароль программа не видит. Ключ доступа хранится в `gdrive.json`, зашифрованный DPAPI (только этот пользователь Windows). Можно подключить несколько аккаунтов; ПКМ по аккаунту → «Отключить».

### Управление файлами на Диске (с версии 1.3.3)

Панель под разделами: «＋ Папка» (Ctrl+Shift+N), «✎ Переименовать» (F2), «➜ Переместить» (окно выбора
папки, «Копировать сюда»; или перетащить выделенное на папку в списке / на «хлебную крошку»), «👥 Доступ»
(по ссылке: закрыт / читатель / комментатор / редактор, люди по почте, письмо — по галочке), «★ Пометить»,
«🗑 В корзину» (Delete). Ctrl+Z или кнопка в уведомлении отменяет последнее перемещение или удаление в корзину.
В «Корзине»: «↩ Восстановить», «✖ Удалить навсегда», «Очистить корзину». Навсегда удаляется только то, что
уже в корзине (проверка на стороне программы). Заголовки таблицы сортируют (имя, владелец, дата, размер).
**Ссылки не меняются** при перемещении и переименовании — у файла в Google Диске ссылка привязана к ID.
Ломает ссылку только удаление: перед отправкой в корзину файлов с открытым доступом программа предупреждает.

## Что программа меняет в системе (только раздел текущего пользователя HKCU)

- автозапуск `--background` (выключается в настройках);
- регистрация моста для расширения (Chrome, Edge, Brave, Yandex);
- обработчик `.torrent` и `magnet:` — только по кнопке в настройках.

Данные программы: `%LOCALAPPDATA%\MairdiDownloader` (настройки, список закачек, компоненты).
